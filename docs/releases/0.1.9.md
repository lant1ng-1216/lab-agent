## Lab Agent 0.1.9

### Chat and interaction
- Separate quoted assistant excerpts from the user's follow-up text in message bubbles.
- Improve message editing, resending, and withdrawal flows, including restoring withdrawn text to the composer and confirming destructive follow-up actions.
- Add selectable assistant text for focused follow-up questions.
- Improve chat scrolling so new output is followed by default while manual browsing remains possible and follow mode can resume.
- Keep tool activity from repeatedly flashing the tools panel, and refine approval/follow-up interactions so they do not trap chat scrolling.
- Improve code, terminal output, and other structured Markdown blocks with clearer, lighter visual hierarchy.

### Reliability and product identity
- Improve engine discovery and diagnostics, and distinguish tool/permission waits from genuine unresponsive turns.
- Keep the product's memory and configuration under Lab Agent's own profile rather than inheriting Claude Code user data or environment overrides.
- Improve local persistence and model/API configuration presentation.
- Show reported token usage without presenting speculative context-window percentages as authoritative.
